audioswitchWindows 音频设备快捷切换 / 自动切换

  • 零第三方依赖
  • 不需要管理员权限
  • 不注入进程，反作弊友好
  • 播 + 录音一起切
  • 开机自启

1快速开始

程序已经装好并配置完成，通常你只需要知道三件事：它现在在跑、怎么手动切、怎么加游戏。

它已经在跑了

守护进程开机自启，负责托盘图标、热键、以及「开游戏自动切耳机」。

手动切

双击桌面的 切换音频设备，或按 Ctrl+Alt+F3。

加游戏

把游戏的 .exe 名字加进 config.toml 的 [[rules]]。

需要检查状态时

:: 打开桌面上的「audioswitch 命令」快捷方式，或手动：
cd C:\Users\youtao\audioswitch
aswitch.cmd status

输出第一行就是守护进程状态：

守护进程: [运行中]
可用 profile: 耳机, 音响

  播放/console         扬声器 (Misiom-Scorpio) (misiom_scorpio)
  ...
当前设备符合 profile: 耳机
自动切换规则: 1 条
当前命中的规则: yuanshen.exe -> 耳机

2日常使用

四种切换方式，随便挑一种顺手的。

桌面快捷方式

切换音频设备：双击就在 耳机 ⇄ 音响 之间切换，不弹窗。

audioswitch 命令：开控制台，先显示状态和命令速查，然后可以继续敲命令。

托盘菜单

右键托盘图标：

 耳机        ← 当前使用的有对勾
 音响
────────────
切换（toggle）
添加应用…
重载配置
打开配置文件
退出

全局热键

Ctrl+Alt+1切到耳机
Ctrl+Alt+2切到音响
Ctrl+Alt+3两者互切

想换成别的组合改 [hotkeys] 即可。如果改成 Alt+F1 这类被 NVIDIA App 占着的键，日志会报 1409，先在 NVIDIA App → 设置 → 快捷键里改掉。

自动

检测到规则里的游戏进程 → 自动切耳机；游戏全部退出 → restore_delay 秒后自动切回音响。

热键用的是什么技术？ 系统级 RegisterHotKey，不装键盘钩子、不注入任何进程，所以 Vanguard / EAC 这类反作弊不会管它。

3命令速查

在项目目录下用 aswitch.cmd <命令>，等价于 python -m aswitch <命令>。

命令说明
aswitch status当前默认设备 + 守护进程状态 + 当前命中的规则
aswitch use 耳机切到某个 profile（支持中文名）
aswitch toggle在 [settings] toggle 的两个 profile 间切换
aswitch list [-a]列出音频设备，-a 含未连接/禁用的；--json 输出 JSON
aswitch start / quit后台启动 / 停止守护进程
aswitch help命令速查（中文）
aswitch watch只打印规则命中情况，不切设备 —— 用来查游戏的进程名
aswitch launch --profile 耳机 -- "C:\game\game.exe"先切设备，再启动程序（对付启动时锁死音频的游戏）
aswitch config --open打印/打开配置文件
aswitch init [-f]按当前设备重新生成配置模板（-f 覆盖，会丢掉中文改名）
aswitch rules列出每个 profile 下有哪些程序（看“加到哪了”）
aswitch learn [exe]收录当前前台程序（或指定 exe）到规则，等效于 Ctrl+Alt+Shift+1
aswitch add [exe]添加应用：不给参数就弹图形选择器；给了 exe 就直接写进规则。两者都会通知守护进程立即生效
aswitch remove <exe>从规则里移除应用（别名 rm）
aswitch daemon [--no-tray] [--no-hotkeys] [--no-watch] [--dry-run]前台运行守护进程，调试用

4配置文件

位置：C:\Users\youtao\audioswitch\config.toml，改完在托盘里点「重载配置」即可生效。

# ---- 全局设置 ----
[settings]
poll_interval = 1.0        # 进程轮询间隔（秒）
restore_delay = 3.0        # 规则进程全部退出后，延迟多久还原设备
notify = true              # 切换时弹托盘气泡
toggle = ["耳机", "音响"]

# ---- 设备别名 -> 端点 ID（不要改成设备名，ID 才是稳定的）----
[render]
high_definition_audio_device = "{0.0.0.00000000}.{0a7f0f97-...}"   # 音响
misiom_scorpio               = "{0.0.0.00000000}.{b697db47-...}"   # 耳机

[capture]
misiom_scorpio               = "{0.0.1.00000000}.{089ca479-...}"   # 耳机麦克风

# ---- profile：一套"用到哪些设备"的组合 ----
[profiles."耳机"]
render  = "misiom_scorpio"
capture = "misiom_scorpio"
# comm_render  = "misiom_scorpio"   # 可选：单独指定"通信设备"（Discord/游戏语音）

[profiles."音响"]
render = "high_definition_audio_device"

# ---- 自动切换规则 ----
[[rules]]
exe = ["cs2.exe", "valorant-win64-shipping.exe", "yuanshen.exe", ...]
profile = "耳机"
enabled = true

# ---- 全局热键 ----
[hotkeys]
"ctrl+alt+1" = "耳机"
"ctrl+alt+2" = "音响"
"ctrl+alt+3" = "toggle"

几个要点

别名指向端点 ID设备名会随驱动/语言变，{0.0.0.…}.{GUID} 不会。用 aswitch list 查看。
同一个别名可以在两个表里同一台设备的播放端点和录音端点常同名，程序会按上下文取对的那个。
三个角色一起切每个设备都设 console / multimedia / communications，否则 Discord、游戏语音不会跟着切。
profile 名随便取中文也行，但改名要同步改三处：toggle、rules.profile、hotkeys 的值。

5自动切换规则

流程：进程出现 → 切耳机；进程全部退出 → 等 restore_delay 秒 → 还原成进入前的设备。

最快：在游戏里按 Ctrl+Alt+Shift+1 —— 自动把当前前台程序收录进耳机规则并立即切过去，下次启动自动生效。 托右键也有「➕ 把「原神」加入 耳机」和「正在运行的程序 ▸」子菜单，效果一样。

要批量管理/删除：aswitch add 打开管理窗口。 顶部只有一个下拉框「当前 profile」：选哪个就只显示哪个的规则，双击添加也加到它。

用管理窗口（删除 / 摆渡）

顶部卡片：左边选 profile，右边直接显示它会切到哪个设备 （例：耳机 → 扬声器 (Misiom-Scorpio)）。右上「＋ 收录当前程序」等于热键收录。

单击右侧「＋ 未添加 / ✓ 已添加」列即可增删（不用双击、不用右键）。 搜索框支持按程序名/进程名实时过滤；输入 xxx.exe 回车可直接添加。 双击行、或选中后按 Enter/Delete 也能切换。

灰行 = 还没加进当前 profile；正常色 = 已经在规则里。窗口大小和上次选的 profile 会被记住。 每行左侧的程序图标是从 exe 里直接提取的（零依赖，取不到时用系统通用图标）。 命令行里用 aswitch rules 可一次列出所有 profile 的规则。

  1. 找到游戏的进程名

    在控制台执行 aswitch watch，然后启动游戏，看输出：

    命中 yuanshen.exe -> profile 耳机

    这里要填的是 进程名，不是路径、也不是快捷方式名。

  2. 加进配置

    [[rules]]
exe = [
  "yuanshen.exe",
  "starrail.exe",
  "*shipping.exe",   # 支持通配符
]
profile = "耳机"
enabled = true

  3. 重载

    托盘右键 → 重载配置，或 aswitch quit 再 aswitch start。

    用 aswitch status 确认「当前命中的规则」显示正确。

游戏启动时就把音频设备锁死了？ 个别游戏（WASAPI 独占、部分 Unity/UE）在初始化时固定设备，运行中再切会没声音。 用 aswitch launch --profile 耳机 -- "游戏.exe" 先切再启动最稳。

6工作原理

为什么这么实现 —— 以及为什么它不需要任何第三方库。

环节做法原因
切换默认设备 未文档化 COM 接口 IPolicyConfig::SetDefaultEndpoint Windows 没有公开 API，同类工具都走这个接口
三个角色 设备设 eConsole / eMultimedia / eCommunications 只设前两个的话，语音类应用不会跟着切
设备枚举 IMMDeviceEnumerator + IPropertyStore 拿到稳定的端点 ID、友好名、在插/未插状态
进程检测 Toolhelp32 快照轮询（默认 1s） 无依赖、开销极小
热键 RegisterHotKey 系统级注册、零注入，不会被反作弊针对
托盘 Shell_NotifyIcon 同上，纯 Win32，无依赖

安全边界

只做三件事：读默认设备、写默认设备、读进程名列表。不注入、不读写游戏内存、不改注册表、不需要管理员权限。

7常见问题

开了游戏没有自动切换

九成是守护进程没在跑。先看 aswitch status 第一行：

守护进程: [未运行]  →  aswitch start

如果显示 [运行中]，就看最后一行「当前命中的规则」：没有命中说明进程名不对，用 aswitch watch 拿真名。

切了，但游戏里还是从音响出声

游戏在启动时锁定了音频设备。用 aswitch launch --profile 耳机 -- "游戏.exe" 先切后启动，或先按热键切好再开游戏。

耳机没插的时候点了切换没反应

这是故意的：目标设备状态不是 active 时程序拒绝切换，否则会直接静音让你以为坏了。插上耳机再切一次即可。

游戏退出后没切回音响

检查 restore_delay（默认 3 秒）。另外如果中途手动按过热键，游戏退出时仍会按「进入游戏前」的快照还原；想要永远回音响，把 restore_delay 调小或改成手动热键。

热键没反应

可能被别的程序占用（错误码 1409）。aswitch.log 里会写「注册热键失败」。换一组组合，或改 [hotkeys]。

另外：如果游戏以管理员身份运行，非管理员的热键可能收不到，此时把守护进程也用管理员启动。

怎么彻底停掉 / 怎么开机自启

停掉：托盘右键退出，或 aswitch quit。

开机自启已经配好 —— 快捷方式在 %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\audioswitch.lnk，删掉它就不再自启。

看日志

C:\Users\youtao\audioswitch\aswitch.log。前台调试：aswitch daemon --verbose。

8文件与维护

目录结构

audioswitch/
├─ aswitch/            程序包
│  ├─ com.py           COM 基础设施（ctypes）
│  ├─ devices.py       端点枚举 / 默认设备
│  ├─ policy.py        IPolicyConfig（真正的切换）
│  ├─ config.py        配置读写 + 首次生成
│  ├─ engine.py        profile 应用 / 快照还原
│  ├─ watcher.py       进程轮询 + 规则状态机
│  ├─ hotkey.py        RegisterHotKey
│  ├─ tray.py          托盘图标与菜单
│  ├─ picker.py        图形化添加应用（tkinter）
│  ├─ appicon.py       exe 图标 → PNG（零依赖）
│  ├─ appnames.py      exe → 程序名（Steam/注册表/版本信息）
│  ├─ ipc.py           具名事件 IPC（quit / reload）
│  └─ cli.py           命令行
├─ assets/
│  ├─ aswitch.png      图标源图
│  ├─ aswitch.ico      多尺寸图标
│  ├─ make-ico.ps1     PNG → ICO
│  ├─ preview-ico.ps1  ICO 各尺寸预览
│  └─ make-shortcuts.ps1 重建桌面快捷方式
├─ config.toml         你的配置
├─ aswitch.cmd         命令行入口
├─ aswitch-shell.cmd   命令控制台
├─ aswitch-daemon.vbs  静默启动
└─ aswitch.log         运行日志

换图标

把自己的 PNG 存成 assets\aswitch.png，然后：

cd assets
powershell -ExecutionPolicy Bypass -File make-ico.ps1 `
  -Source aswitch.png -Output aswitch.ico

# 可选：检查 16px 下能不能看清
powershell -ExecutionPolicy Bypass -File preview-ico.ps1 `
  -Ico aswitch.ico

# 重启托盘
aswitch quit && aswitch start

脚本会按 alpha 通道自动裁掉多余留白（留 4%），并生成 16/20/24/32/40/48/64/128/256 九个尺寸。

重建桌面快捷方式

powershell -ExecutionPolicy Bypass -File assets\make-shortcuts.ps1

维护提示：.cmd 批处理只能写 ASCII —— cmd.exe 按 OEM 代码页（中文系统是 GBK）读文件，存 UTF-8 中文会把命令拆坏。中文提示都放在 Python 里（aswitch help）。
